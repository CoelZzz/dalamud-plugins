# CoelZzz's Dalamud plugins

A custom Dalamud plugin repository.

## Install

1. In game, open Dalamud Settings (`/xlsettings`) → **Experimental**.
2. Under **Custom Plugin Repositories**, paste this URL, click **+**, then **Save**:

   ```text
   https://raw.githubusercontent.com/CoelZzz/dalamud-plugins/main/repo.json
   ```

3. Open the plugin installer (`/xlplugins`) and search for the plugin.

## Plugins

| Plugin | What it does |
|---|---|
| Raid Helper | Live mechanic calls for high-end fights. Currently covers Dancing Mad (Ultimate) and The Epic of Alexander (Ultimate). Open its settings with `/raid`. |

Updates arrive through Dalamud like any other plugin.
